Proceso

Bitácora de desarrollo

Registro del proceso del TP1: decisiones, problemas y ajustes realizados para que el código sea claro, mantenible y revisable.

01 · Organización

Se definieron cinco perfiles y responsabilidades: Data & Routing, Product & Frontend, Backend, UX/UI & QA y DevOps & Docs.

02 · Arquitectura

Se separaron responsabilidades en HTML por página, CSS global en css/syle.css y scripts específicos por rol en js/. Las imágenes viven en img/.

03 · Responsive y accesibilidad

Breakpoints explícitos en 400 px, 900 px y 1200 px, foco visible, skip-link, labels, alt, navegación por teclado y prefers-reduced-motion.

04 · Performance

Logo, hero de portada y foto hero de cada perfil usan carga prioritaria. Tarjetas inferiores usan loading="lazy" y dimensiones explícitas para reducir CLS.

05 · Interactividad

Portada: optimización de rutas y tema persistente. Cada perfil tiene una interacción propia. Los álbumes usan patrón Facade.

06 · Privacidad e IA

Los avatares son ilustraciones de demostración para evitar exponer fotografías personales. La IA debe documentarse como asistente y cada resultado debe ser revisado y adaptado por el equipo.

07 · Próxima evolución

TP2: backend real, datos de rutas, pruebas automatizadas, medición de Core Web Vitals y reemplazo de placeholders.

Checklist de revisión

✓ HTML5 semántico y navegación interna
✓ CSS propio + Google Fonts
✓ Responsive 400 / 900 / 1200 px
✓ JavaScript portada + 5 perfiles
✓ ALT, ARIA y foco visible
✓ Lazy loading + fetchpriority
✓ Código comentado y organizado por responsabilidad
✓ Pruebas de navegación y accesibilidad documentadas
